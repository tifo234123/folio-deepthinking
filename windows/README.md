# Folio Deepthinking for Windows

1. Download [`FolioDeepthinking.exe`](FolioDeepthinking.exe) (open it, then **Download raw file**), or take it from the latest Release.
2. Put it in its own folder and double-click it. The first start takes a few seconds while it unpacks.
3. The app is unsigned, so SmartScreen may warn: choose **More info → Run anyway**.

Windows 10 or 11, 64-bit. Your library, database and API keys are stored in a `data` folder created next to the `.exe`.
