# Folio Deepthinking for Windows

1. Download `FolioDeepthinking-windows-x64.zip` and extract it (right-click → *Extract All*).
2. Open the extracted `FolioDeepthinking` folder and run `FolioDeepthinking.exe`. Keep `_internal` beside it.
3. Windows SmartScreen may warn because the app is unsigned: choose *More info* → *Run anyway*.

Windows 10 or 11, 64-bit. Your library, database and API keys are stored in a `data` folder created next to the `.exe`.
